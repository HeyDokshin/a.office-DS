Как всё работает

По умолчанию задачи сортируются по важности в зависимости от правил, которые задаёт администратор
Умная очередь задач
Правила сортируются по приоритету. Самые приоритетные задачи находятся сверху списка
Список задач и ручной режим
Если включены фильтры или сортировка — задачи сортируются в ручном режиме, алгоритмы выключены
Архивные задачи
Исполненные и отклонённые задачи сортируются по дате закрытия
Срок в норме
Задачу можно выполнить в обычном темпе, нет риска нарушения срока
Срок истекает
У задачи подходит срок исполнения, назначенный администратором
!
Срок истёк
У задачи истёк срок исполнения. Обработайте задачу в рамках регламента вашего отдела
Фильтры
Таблицу можно отфильтровать, чтобы найти нужную задачу. Если применить фильтры, список задач будет работать в ручном режиме
Обновление в реальном времени
Таблица обновляется автоматически, как только меняются задачи. Новые задачи в начале списка появляются с синим индикатором
Одна задача
Чтобы сосредоточиться на самом важном
  • В разделе Мои показывается только одна задача: та, что в работе, а если такой нет — самая приоритетная назначенная
  • Раздел Общие скрыт
  • Аналитика скрыта
Многозадачность
Чтобы работать со всеми задачами
  • Отображаются задачи всех статусов
  • Ограничений по количеству задач нет
  • Раздел Общие доступен
  • Аналитика доступна
