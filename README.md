# a.office-DS — прототип SmartBackOffice «Умная очередь»

Интерактивный прототип на дизайн-системе Альфа-Банка: список задач, окно задачи со встройкой РК, клиенты, карточка клиента, справочники, поиск по модулю и отчёты ВК, навигация, создание задачи.

Как устроен прототип, как его менять и проверять — в [docs/SPEC.md](docs/SPEC.md).

## Состав

- `project/` — прототип. Каждый `*.dc.html` — компонент или доска (состояние экрана). `canvas.json` — раскладка досок по страницам канваса.
  - Основные компоненты: `Main` (очередь и вся навигация), `Task`, `ClientSearch`, `ClientCard`, `Refs`, `ModuleSearch`, `ModuleReports`, `CreateTask`, `Header`, `SideMenu`.
  - `Coverage.dc.html` — что собрано из макетов Figma и чего нет.
  - `TableStandard.dc.html` — правила таблиц и общие правила интерфейса.
  - `ds/alfa-bank/` — токены и сборка компонентов дизайн-системы.
- `tests/` — автотесты (Node + headless Chrome по CDP).

## Как открыть

```bash
python3 -m http.server 8791 --directory project
# http://127.0.0.1:8791/Main.dc.html
```

## Как проверить

Нужны Node 22+ и Google Chrome (macOS).

```bash
tests/run-all.sh        # все наборы, смоук по всем доскам и большой автотест очереди
```

После правок `:hover`-стилей перегенерируйте правило паузы 0,3 с: `python3 tests/tools/hover.py project`.

## Известные ограничения

- Данные вымышленные.
- Не собраны: виджет задач, страница звонка, списки задач кредитования, админка.
- «Выйти без сохранения?» показывается, только если в окне задачи были изменения; по спеке — по времени с последнего сохранения.
- Токена `--color-light-neutral-translucent-400-inverted` в локальных токенах нет, стоит запасной цвет.
