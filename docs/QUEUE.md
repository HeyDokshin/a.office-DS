# Спека: «Умная очередь» — список задач

Страница, с которой сотрудник валютного контроля начинает работу: видит свои и общие задачи, берёт их в работу, передаёт, ставит на холд, закрывает. Здесь описано, как она устроена в прототипе и как должна работать в реализации. Общие правила интерфейса (шторки, ховеры, топбар таблиц, подложки) — в [SPEC.md](SPEC.md), раздел 6.

- **Компонент:** `project/Main.dc.html` — очередь и корень приложения.
- **Макеты:** Figma «Список задач» `7boNgcJJQe2NUEVghkadNz`: «Список задач / ВК» 7188:43678, закреплённая шапка таблицы 11234:62899, фильтры 10001:249643, «Как всё работает» 10001:249642.
- **Доски канваса** (страница «Список задач»): `Main` — основной вид, `MainCard` — вариант меню 2, `MainV3` — вариант 3, `StateLoading`, `StateEmpty`, `StateNotFound`, `StateError` — состояния.

## 1. Состав страницы

Сверху вниз:

1. **Шапка приложения** — общая для всех страниц (поиск, звонки, профиль, «Назад»).
2. **Заголовок «Умная очередь»** с иконкой робота (тултип «Задачи назначает робот») и бейджем «Без перебоев».
3. **«Направление: …»** — выпадающий список направлений (валютный контроль, кредитование ЮЛ / ФЛ).
4. **Статус обновления** — «Обновляется автоматически, 100% времени онлайн».
5. **Блок текущей задачи** — «Перейдите к текущей задаче: …» и число задач в работе. Появляется, если у сотрудника есть задача в работе.
6. **Кнопки действий** — «К текущей задаче», «На холд», «Скачать таблицу», меню «Ещё». Справа ссылка «Как это работает?» открывает шторку с объяснением правил очереди.
7. **Строка фильтров** (раздел 3).
8. **Виджет аналитики** — счётчики «В очереди», «В работе», «Назначено», «Не назначено», «Холд», «Не нарушено», «Истекает», «Просрочено». Включается и выключается кнопкой «Виджет аналитики» в строке фильтров.
9. **Топбар таблицы**, **таблица**, **нижняя панель** (разделы 4–7).

## 2. Вкладки

| Вкладка | Что показывает |
|---|---|
| Мои | Задачи, назначенные на сотрудника. Открывается по умолчанию |
| Общие | Все задачи направления; появляется колонка «Исполнитель» |
| Архив | Закрытые задачи; действий взятия в работу нет |

## 3. Фильтры и поиск

- **Поиск** «Название, ID, Клиент» — с первого символа, сразу, без кнопки. Совпадения подсвечиваются.
- **Быстрые признаки** — кнопки-иконки: «Срочно», «Корректировка», «Консалтинг», «Письмо-платёж», «Зачисление рублей». Можно включить несколько.
- **Выпадающие фильтры** — «Направление», «Срок», «Тип», «Статус». Выбранное значение показывается в чипе, у чипа есть крестик сброса.
- **Расширенный поиск** — кнопка с ползунками открывает шторку справа со всеми полями фильтра.
- **Размер таблицы** — три кнопки:
  - маленький: задача в одну строку;
  - средний: по умолчанию;
  - большой: увеличенный шрифт.
- Если фильтры ничего не нашли, вместо таблицы показывается состояние «Ничего не нашлось» с кнопкой сброса фильтров.

## 4. Топбар таблицы

- **Слева.** «Всего N» — число задач с учётом фильтров. Когда выбраны строки — «Выбрано N». Рядом «Выбрать все»: отмечает все строки текущей страницы; когда страница выбрана целиком, кнопка называется «Снять выбор».
- **Справа:**
  - «Обновить» (иконка) — иконка прокручивается, приходит уведомление «Таблица обновлена»;
  - разделитель;
  - «Группировка» (только в расширенном виде) — «Без группировки», «По статусу», «По типу задачи»;
  - «Настройки» — шторка «Настройки таблицы»: переключатель «Расширенный вид», список столбцов с чекбоксами и перетаскиванием для порядка, «Сбросить всё»;
  - «Скачать таблицу» — уведомление «Файл готов к скачиванию» или, при ошибке, «Не получилось скачать таблицу».

## 5. Таблица

### Столбцы

| Столбец | Содержимое | Тултип / клик |
|---|---|---|
| Чекбокс | Выбор строки | — |
| ID | ID задачи, ниже номер в системе-источнике (РК). Синяя точка — новая задача | Клик копирует; тултип «Скопировано» |
| Статус | Бейдж статуса, ниже «12с назад» | Когда получен статус; для холда — причина |
| Задача | Тип задачи, система «РК · РК», иконки признаков, теги: номер, сумма, связанные задачи, «Бутик ВК + ещё 3» | Клик копирует; «+ ещё N» раскрывает список тегов |
| Клиент | Название, код клиента и ИНН, теги клиента (СКБ, сегмент, «Авиа», «Агент»…) | Полное наименование; клик открывает карточку клиента |
| Исполнитель | Только во «Общих»: ФИО, как назначена и когда | Клик копирует |
| Поступило | Время и дата | Пояснение про часовой пояс |
| Срок | Таймер SLA (кольцо), «SLA 4 д 12 ч», крайний срок | Заложено, осталось или просрочено, рабочее или календарное время |
| ▶ | «Взять в работу» / «Пауза» | Пока открывается другая задача — недоступно |
| ⋯ | Меню строки (ниже) | — |

### Статусы

| Статус | Цвет |
|---|---|
| Назначено | синий |
| Не назначено | оранжевый |
| В работе | фиолетовый |
| Холд | красный |
| Закрыта | серый |

### Меню строки «⋯»

- **Действия над задачей:** «Закрыть задачу», «Отклонить задачу», «Передать другому».
- **Данные задачи:** «Карточка клиента», «История изменений», «Изменить данные».
- **Правила работы:** «К правилу SLA», «К правилу приоритизации», «К модели обслуживания».

### Виды

- **Обычный.** Ячейки переносят текст.
- **Расширенный** (включается в настройках). Горизонтальная прокрутка, первые и последние столбцы закреплены, доступна группировка.
- **Маленький размер.** Мини-таблица: задача в одну строку. Всё, что не поместилось, показывается в тултипах — система задачи, код и ИНН клиента, когда получен статус, причина холда, как и когда назначен исполнитель, полный срок SLA.

### Поведение

- **Заголовок таблицы** прилипает под шапку приложения. Шапка и заголовок делят одну подложку: сверху цвет фона страницы, к заголовку таблицы — белый, ровно по ширине таблицы.
- **Тултипы** появляются через 0,3 с. Тултип строки у верхнего края таблицы открывается вниз, чтобы не перекрываться шапкой.
- **Строки по 10 на страницу.** Можно выбрать 10, 20 или 50 — «Показывать по N» в нижней панели.
- **Клик по строке** открывает окно задачи. Клик по чекбоксу, кнопке, ссылке или меню строку не открывает.
- **Чекбоксы** стоят по центру первой строки текста во всех трёх размерах таблицы.

## 6. Нижняя панель

- **Без выбора.** «Показывать по N» слева, пагинация справа.
- **С выбором** панель превращается в панель действий:
  - чекбокс с числом выбранных — нажатие снимает выбор;
  - «Передать задачу» (тёмная), «Поставить на холд», «Закрыть задачу», «Ещё» — внутри «Отклонить»;
  - пагинация «1 из N страниц» справа.
- **Ограничение:** передать можно не больше 50 задач за раз. При превышении кнопка недоступна, в тултипе «Можно передать только 50 задач за раз».
- **Вид панели.** Панель прилипает к низу экрана. Сверху фейд с прогрессивным блюром на 28 px, ниже почти непрозрачная белая подложка — строки под кнопками не читаются.

## 7. Живая очередь (события сервера)

В прототипе события имитируются таймерами (проп `stream`: `on` / `off`); в реализации это поток событий сервера.

- **Новая задача** въезжает сверху списка с подсветкой и синей точкой. Приходит уведомление «Назначена новая задача». Новые задачи показываются только на странице очереди.
- **Задачу взял другой исполнитель.** Строка заменяется плашкой «Задачу «…» с ID … взял другой исполнитель» с кнопками «Не уведомлять» и «Перейти к задаче». Плашку можно закрыть.
- **Закрытие задачи.** Строка уезжает с анимацией. Если задач не осталось — «Задач больше нет».
- **Уведомления** идут в общий стек: максимум три, по одному каждого типа. Однострочные выровнены по центру.

## 8. Действия и их результаты

| Действие | Где | Результат (уведомление) |
|---|---|---|
| Взять в работу | ▶ в строке, «К текущей задаче» | «Открываем задачу» → окно задачи; статус «В работе» |
| На холд | Кнопка над таблицей, панель выбора | Шторка с причиной холда → «Задача переведена на Холд» / «Задачи поставлены на холд» |
| Передать | Меню строки, панель выбора | Шторка выбора сотрудника → «Задача передана» / «Задача не передана» |
| Закрыть | Меню строки, панель выбора | «Задачи закрыты» / «Не получилось закрыть задачи» |
| Отклонить | Меню строки, «Ещё» в панели | «Задачи отклонены» |
| Скачать таблицу | Топбар, кнопки над таблицей | «Файл готов к скачиванию» / «Не получилось скачать таблицу» |

Все модалки — шторки справа (отступ 8 px, ширина 500 px, Esc закрывает). Проп `failActions` включает сценарии ошибок.

## 9. Состояния страницы

| Состояние | Проп `scenario` | Что видно |
|---|---|---|
| Данные | `data` | Таблица |
| Загрузка | `loading` | Скелетоны строк, счётчики виджета — «—» |
| Нет задач | `empty` | Пустое состояние с пояснением |
| Ничего не нашлось | `notfound` | Пустое состояние и «Сбросить фильтры» |
| Ошибка | `error` | «Не получилось загрузить» и «Попробовать ещё раз» |

Прочие пропсы: `layout` (`classic` / `v3` — вариант с блоком «Работа в системе начата»), `menuLook` (`flat` / `card` — вариант левого меню).

## 10. Что проверяют тесты

- **`tests/autotest.mjs`** (через `run-autotest.sh`, около 2900 проверок):
  - каждый тултип появился, стоит не дальше 12 px от текста, не уходит за экран и не перекрыт;
  - фильтры, поповеры, иконки, колонки;
  - фон и разделитель закреплённых ячеек — во всех размерах и видах, на 1440 и 1100 px.
- **`uitest`, `taskflow`, `notifytest`** — действия, переход в окно задачи, уведомления.
- **`selcheck`** — «Выбрано N» и «Выбрать все» / «Снять выбор».
- **`hovertest`** — пауза 0,3 с у ховеров и тултипов.

## 11. Что в прототипе условно

- **Данные вымышленные.** Счётчики виджета и число задач не связаны с бэкендом.
- **Направления «Кредитование ЮЛ / ФЛ».** В выпадающем списке есть, но списков задач по ним нет.
- **Правила SLA, приоритизации и модель обслуживания.** Пункты меню строки показывают уведомление, отдельных страниц нет.
- **«Изменить данные» и «История изменений» из меню строки** открывают окно задачи, без отдельной формы.
